# 文字、科学一致性与跨文件检查清单

完整模式覆盖以下各类；窄范围模式只应用相关类别。对未发现问题的类别可简述，对无法读取的类别标注范围。工具只能提取文字时不能宣称完成图片、公式外观、隐藏文字和修订检查。所给文件全文均需纳入；长文按段分批记录完成进度。

## 1. 文件与元信息

- 标题/短标题、稿号、期刊、返修轮次、页眉页脚、文件名是否残留旧版本信息。
- 作者拼写、顺序、单位及编号、共同作者标记、邮箱、ORCID、CRediT 缩写和姓名是否一一对应；作者变动只标记差异，不自行判断已获同意。
- 基金及编号、致谢、伦理审批、利益冲突、数据和代码可用性声明，按适用研究类型核对。
- clean 与 tracked 版本的最终可见内容是否一致；缺一种不声称已比较。

## 2. 遗漏、重复和含义

- 重复字词/句段/标题/图注/引用，半句、缺主宾语、否定词遗漏、复制粘贴残留、占位符、交叉引用报错。
- `this/these/respectively` 指向、比较对象、指标、方向、条件及范围是否明确；区分语言歧义与事实信息缺失。
- 摘要概括、独立图注定义、回复引用修订文字可合理重复；不以“重复”机械删除。
- 明确拼写、冠词、时态、单复数、标点问题给最小修改；不把风格偏好当错误。

## 3. 缩写和数学表达

- 建立工作对照：缩写/全称/首次出现/跨文件写法。分别考虑摘要、正文、SI 和独立图注，不机械展开标准单位和允许的常用缩写。
- 同缩写多义、同概念多名、模型/产品/组别名称、变量、连字符、大小写、上下标、希腊字母、负号和单位是否一致。
- 公式是否可读、变量定义与实际计算是否一致，差值方向、归一化分母、比例和百分比是否混淆。提取丢失 OMML 或嵌入公式图时先查看，不将提取器输出的 image/空白直接认定为稿件错误。

## 4. 数字、方法与证据

- 摘要、方法、结果、图表、讨论、回复和 SI 的关键数值逐一对照：样本量及单位、筛选阈值、参数、时间范围、分组、效应方向、P 值、置信区间。
- 样本数与观测次数、独立重复与技术重复、全体与子集分开；总和/百分比考虑缺失、多选和四舍五入，勿凭表面不同判矛盾。
- SD、SE/SEM、置信区间、误差条、显著性符号与检验定义；无数据仅做报告一致性，不声称统计复算。
- 数据来源、时空分辨率、时间匹配、重采样、质量筛选及参数、基线定义、缺失处理、验证独立性是否足够复现已报告分析。
- 结果新增分析是否有相应方法；相关与因果、显著与实用意义、不显著与无效、局部证据与普遍外推不得混同。
- 遇到事实冲突，分别引用双方并标记待核实真实做法。若缺相关证据，优先寻找现有结果、收窄论断或补充限制；仅当审稿问题确实未回答时指出证据缺口，不自动要求无关新实验。

## 5. 图表和 SI

- 建立“正文引用—实际图表—图注/表注”对照，含主文、SI、回复中的独立图表编号；连续唯一、引用存在、图存在但未引用、旧编号残留。
- 实际查看支持论断的分面、方向和对照；图中标签、颜色、图例、坐标轴、单位、时间、样本数、统计标记与图注一致。
- 图注/表注需必要缩写、误差条、检验及样本解释；表头、数值对齐、有效数字合理。
- 如可视：可读性、裁切、遮挡、遗漏图例、可能误用面板；仅凭相似不认定图像不当处理。嵌入图与独立图版本对应。
- SI 目录、章节、附件清单、图表数量与内容匹配；正文所说补充分析真实存在并支持所声称的结论。影响解释的补充方法需恰当引用。
- 额外数据/代码/视频清单与实际文件或可访问链接核对；不可访问明确标注。

## 6. 回复与投稿信

- 原始意见是否完整收录、正确归属和编号；原始审稿材料缺失时不声称核对完整性。
- 回复对每个子问题直接回答；所称新增/删除/修改已落实或明确有理由不改。必要方法不能只存在回复信。
- 同一问题跨 Reviewer 解释一致；总回复和 Cover Letter 的主要修订总结应与正文/SI 一致，不能沿用旧图号或旧结果。
- 引用修订句与最终稿对应；“将要做”的承诺是否完成。详细执行见 comment-audit.md。

## 7. 参考文献与提交规范

- 文内引用与列表双向对应、作者年份/后缀、重复条目、书目信息完整性；SI 独立参考文献体系按期刊要求。
- 书目信息存在不代表原文支持论断。核验 DOI、原文内容、来源真实性或撤稿情况需实际访问权威来源并记录；未核查项不能说已验证。
- 仅将实际查阅的官方指南称为强制要求：字数、结构、匿名、文件格式、图件、必要声明与报告清单；通用建议和风格选择分开。
- 批注、修订、隐藏文字和 clean 残留按工具真实能力检查；最终排版、特殊字符、公式、分页和参考文献需看渲染结果。
- 无外部查重材料不报重复率、不保证无抄袭；最终只能报告本次范围内的发现。
