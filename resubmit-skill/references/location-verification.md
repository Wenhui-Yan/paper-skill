# 最新版本定位与真实行号

## 可接受的行号来源

1. 最新 Word 排版中实际显示的印刷行号。
2. 与该 Word 版本对应、保留真实行号的最终 PDF。检查来源、修改时间或作者指定关系；不能假定同名 PDF 已同步。
3. 从当前 Word 导出的带行号 PDF，可用于核对该次导出；记录导出来源及方式。其他排版引擎可能造成重排，若与提交版不一致，不能冒称提交版行号已验证。

DOCX XML 段落编号、提取文本的第几行、`rg -n`、PDF 提取器的文本行索引都不是印刷行号。DOCX 的行号设置只说明启用了行号，不能由此推算每段行号。若 PDF 提取时行号与正文错序，实际查看该页，不能自动按最近数字匹配。

## 定位操作

- 确认连续编号还是按页/章节重启；重启时同时给页码和行号。页码区分文档印刷页码与 PDF 文件页序。
- 对每个引用先判断论断，再查看其引用范围和上下文，核对是否完整覆盖关键句。可用多个短范围支持复合论断，无需强拉成长段。
- 章节名称必须和最终稿一致。内容实际在 Conclusions 时，回复不能仍称 added to the Discussion。
- 图号需同时核对图本身、图注、分面和正文解释。回复信自己的 Fig. R1 不等同于稿件 Fig. 1；主文与 SI 分开。
- 正确行号、充分且准确的章节或图表定位可保留，不强制每个回复句都加行号；方法背景解释、未采纳理由不一定需要稿件位置。
- 范围只是稍宽而仍完整支持论点时，注明“可保留；可选缩窄”，不当实质错误。引用遗漏关键句、落在图注或指向别处才明确更正。
- 原始审稿意见的旧版 `Line ...` 保留；只修正 Authors' Reply 所指的最新稿位置。

## 无真实行号的降级方案

输出 `Manuscript, Section 4.2, paragraph beginning “...”`，并给必要英文短句；有可靠页码或图表编号可并用。明确“印刷行号未核实”，不要用约数、预测值或段落号伪装为行号。

若用户要求行号而工具不足，继续完成内容匹配并提供锚点；需要最终 PDF 才能核准时说明该依赖，不暂停其他检查。

新建议句定位为“在 Section 4.2 的 ‘[现存句]’ 后增加”；不得为还不存在的句子给当前行号。引用翻译或改写不加引号冒充正文原句。

## 定稿回查

报告记录文件角色、完整路径、修改时间和可用时的 SHA256，以及行号的取得方式与版本。修改正文、图表尺寸、参考文献或接受修订都可能重排；先定稿，再刷新回复信中的位置，最后检查导出的实际提交版。新一轮不能沿用上轮行号；只继承问题 ID 与核验线索。
